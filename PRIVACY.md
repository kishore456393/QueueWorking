# Privacy & Data Protection

This project is designed with privacy in mind.

## 1. User Isolation
- **Private Feeds**: Video feeds and queue zones are linked to the specific user who created them.
- **Session Security**: Detection processes are stopped immediately upon logout.
- **Authentication**: Secure password hashing is used for all user accounts.

## 2. Data Retention
- **Automatic Cleanup**: Detection snapshots (images) are automatically deleted after 1 minute (configurable).
- **Minimal Storage**: We only store the necessary metadata to provide real-time analytics.

## 3. Local Processing
- **No Cloud Uploads**: All video processing happens locally on your machine or server.
- **Video Files**: Uploaded videos stay on your local file system.

## 4. GDPR Compliance
- This system is designed to be self-hosted, giving you full control over your data.
- You can delete your account and all associated data at any time.
