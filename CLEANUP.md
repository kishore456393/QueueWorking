# Files and Folders Safe to Delete

## ✅ Safe to Delete (Backup/Temporary Files)

### Folders:
- `attached_assets/` - Contains old backup files and pasted content
- `.local/` - Local cache directory
- `uploads/` (contents) - Uploaded videos (keep the folder, delete contents if needed)

### Files:
- `replit.md` - Replit-specific documentation
- `.replit` - Replit configuration
- `HOW_TO_RUN.md` - Replaced by README.md
- `design_guidelines.md` - Design notes (not needed for running)
- `postcss.config.js` - If not using PostCSS separately

## ⚠️ DO NOT DELETE (Required Files)

### Essential Folders:
- `client/` - Frontend React application
- `server/` - Backend Express.js server
- `detector/` - Python YOLO detection service
- `shared/` - Shared TypeScript types
- `node_modules/` - Node.js dependencies (can be regenerated with `npm install`)
- `.venv/` - Python virtual environment (can be regenerated)

### Essential Files:
- `package.json` - Node.js dependencies configuration
- `package-lock.json` - Exact dependency versions
- `requirements.txt` - Python dependencies
- `tsconfig.json` - TypeScript configuration
- `vite.config.ts` - Vite build configuration
- `tailwind.config.ts` - Tailwind CSS configuration
- `drizzle.config.ts` - Database configuration
- `components.json` - UI components configuration
- `.gitignore` - Git ignore rules
- `README.md` - Main documentation
- `SETUP.md` - Quick setup guide
- `start.bat` - Windows startup script
- `start.sh` - macOS/Linux startup script

## 🔄 Can Be Regenerated

These can be deleted and regenerated by running install commands:

- `node_modules/` - Run `npm install` to regenerate
- `.venv/` - Run `python -m venv .venv` to regenerate
- `dist/` - Run `npm run build` to regenerate

## 📋 Cleanup Commands

### Windows (PowerShell):
```powershell
# Delete backup files
Remove-Item -Path "attached_assets" -Recurse -Force
Remove-Item -Path ".local" -Recurse -Force
Remove-Item -Path "replit.md", ".replit", "HOW_TO_RUN.md", "design_guidelines.md"

# Clean uploaded videos (optional)
Remove-Item -Path "uploads\*" -Exclude ".gitkeep"
```

### macOS/Linux:
```bash
# Delete backup files
rm -rf attached_assets/ .local/
rm -f replit.md .replit HOW_TO_RUN.md design_guidelines.md

# Clean uploaded videos (optional)
find uploads/ -type f ! -name '.gitkeep' -delete
```

### Using npm script:
```bash
npm run clean  # Removes all generated files (be careful!)
```

## 📦 Preparing for Distribution

If sharing the project with others, delete:
1. `node_modules/` (users will run `npm install`)
2. `.venv/` (users will create their own virtual environment)
3. `uploads/` contents (except `.gitkeep`)
4. `attached_assets/` (backup files)
5. `.local/` (cache)
6. Any `.log` files

Then create a ZIP file or push to Git repository.

## 🎯 Minimal Project Size

After cleanup, the project should be approximately:
- With dependencies: ~500 MB (includes node_modules and .venv)
- Without dependencies: ~5-10 MB (clean repository)
- With YOLO model: +14 MB (YOLOv8n) or +50 MB (YOLOv8m)

The YOLO model will be automatically downloaded on first run if not present.
